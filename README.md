# Web Ops Automation

**Набор моих небольших Python-инструментов для ежедневной работы с большим количеством сайтов.**

Я сделал этот набор из реальных повторяющихся задач: следить за продлением доменов, массово подключать сайты к хостингу и быстро видеть общую картину по Cloudflare. Цель простая - меньше ручной рутины и меньше риска что-то пропустить.

## Что здесь есть

### 1. Контроль продления доменов
Берёт список доменов из Excel, смотрит даты и решения по каждому домену и присылает в Telegram только то, что требует внимания.

**Зачем:** когда доменов много, ручная проверка кабинетов занимает время и легко пропустить важную дату.

### 2. Массовая работа с cPanel
Показывает уже подключённые домены и помогает добавлять новые списком. Сначала можно запустить безопасную проверку без изменений, а затем применить готовый список.

**Зачем:** одна и та же операция для большого количества сайтов не должна выполняться вручную по одному домену.

### 3. Сводка Cloudflare
Собирает по списку сайтов краткую статистику за сутки и неделю и сохраняет её в один CSV-файл.

**Зачем:** за несколько минут видно, какие сайты получают трафик, а какие требуют проверки.

## Что показывает этот проект

Не только Python-код, а мой рабочий подход к web operations: я вижу повторяющийся процесс, упрощаю его, добавляю проверки и превращаю в инструмент, которым можно пользоваться каждый день.

## Пример результата

В папке `examples` лежат обезличенные примеры Telegram-уведомления и итогового Cloudflare-отчёта.

## Быстрый запуск

1. Установить зависимости: `pip install -r requirements.txt`.
2. Задать нужные переменные окружения по `.env.example`.
3. Для каждого инструмента использовать пример входных данных из репозитория.

Доступы, токены, рабочие домены и другая внутренняя информация в репозитории не хранятся.
